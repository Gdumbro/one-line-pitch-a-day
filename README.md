One sentence that convinces a friend who has never coded to let an AI agent build their first app idea on make.fun. `main.py` (Python 3.13, standard library only) writes the 150-character pitch to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` when set, `/output` otherwise).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
